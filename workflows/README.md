# Workflows de n8n

`buscador-ofertas-laborales.json` es el workflow de ejemplo. Las credenciales y el ID de la instancia se quitaron del export por seguridad. Al importarlo, volvé a asignar las credenciales locales de Ollama y PostgreSQL y configurá la URL de Chat Trigger en `.env`.

Antes de publicar futuras versiones, revisá que los exports no contengan credenciales, datos fijados de ejecución ni información personal.
